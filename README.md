# Automated Defect Detection System Using AI Vision

An industrial-grade anomaly detection system that leverages deep learning models 
(PatchCore, EfficientAD) for automated visual inspection and classification of 
manufacturing defects. Designed for multi-modal input with RGB and depth imaging, 
featuring model fusion, calibration, and real-time inference.

## Key Features
- **Multi-Model Support**: PatchCore and EfficientAD architectures
- **Multi-Modal**: RGB and Depth image processing
- **Model Fusion**: Intelligent score fusion and calibration
- **Defect Classification**: Automatic detection of cut, hole, contamination, and good parts
- **Production-Ready**: Optimized inference pipeline with threshold tuning
